# 레드가드 한국어 패치 0.1.1 — 항구 아이템 화면 충돌 수정

Steam Software RG.EXE용입니다. 0.1.0의 번역·글꼴·색상·게임 실행 파일은 그대로 사용하며, 아이템 화면을 열 때 필요한 일반 메모리 공간을 확보하도록 설치 설정을 추가했습니다.

## 기존 한국어 패치 사용자

1. 게임을 종료하고 0.1.1 ZIP을 새 폴더에 풉니다.
2. `RedguardKoreanPatcher.exe`에서 Steam 게임 설치 폴더 또는 그 안의 `Redguard` 폴더를 선택합니다.
3. **항구 충돌 수정**을 누릅니다. 기존 0.1.0 설치자와 별도 URP 한국어 호환판 설치자 모두 이 버튼을 사용할 수 있습니다.

이 버튼은 한국어 `RG.EXE`와 `ENGLISH.RTX`를 확인한 뒤 `SYSTEM.INI`의 `[3dmanager] heap_kbytes`만 최대 20000으로 조정합니다. 메뉴·키 설정·URP 맵·세이브는 변경하지 않습니다. 이미 20000 이하라면 유지합니다.

## 새로 설치하는 경우

Steam 원본 Software판에서 **패치 적용**을 누릅니다. 기존 네 파일의 한국어 차분과 메모리 설정을 함께 적용합니다. Glide 실행 파일은 지원하지 않습니다.

## 백업과 복원

네 한국어 패치 대상의 원본 백업은 기존 `*.redguard-ko.bak`를 사용합니다. 메모리 설정의 백업은 `SYSTEM.INI.redguard-ko-memory.bak`입니다. 백업을 지우지 마세요.

**원본 복원**은 한국어 패치 파일을 복원하고, 현재 heap 값이 20000인 경우 백업의 heap 값으로 되돌립니다. 설치 후 바꾼 해상도·음량 등은 유지합니다. 사용자가 heap 값을 별도로 변경했다면 그 값도 유지합니다. URP를 설치했다면 URP부터 복원한 뒤 기본 한패를 복원하세요.

## 원인과 확인 범위

0.1.0에서 항구 도착 후 편지 팝업을 열기 직전 `ERROR!(2) Out of memory`, `3dlib.c:435`가 발생했습니다. 이 경로는 아이템용 `3DART\INVENTRY.ROB`의 OARD 데이터 2,281,872바이트를 일반 malloc으로 읽습니다. 모델 파일은 Steam 원본과 일치했습니다.

- 기본 한패, heap 22000: 사용자가 충돌 재현.
- 편지 본문만 영어 원문으로 복원, heap 22000: 같은 충돌 재현.
- 번역을 모두 복구, heap 20000: 사용자가 편지 표시와 정상 진행 확인.

예약하는 3D 매니저 heap을 2,048,000바이트 줄이는 설정으로 해당 모델의 일반 메모리 할당이 성공했습니다. 전체 게임의 모든 지역·아이템에 대한 플레이 검증은 끝나지 않았습니다. 3D 매니저 예약량 감소가 다른 복잡한 장면에 미치는 영향은 추가 검증이 필요합니다.

수동으로 고치려면 게임을 종료한 뒤 `SYSTEM.INI`의 `[3dmanager]`에서 `heap_kbytes=22000`을 `heap_kbytes=20000`으로 바꾸면 됩니다. `texture_kbytes=12000`은 유지합니다.

CLI: `RedguardKoreanPatcher.exe memory-fix GAME_DIRECTORY`.
