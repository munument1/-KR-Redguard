# 메뉴 대비 수정 시험본 v4

실행: `output/engine_utf8/playtest_v4_menu_final_20261013/Play Korean Test.cmd`

사용자가 v3의 인게임 자막과 인트로 색상은 정상이며 메뉴의 밝은 배경과 밝은 테두리가 문제라고 확인했습니다.

- 메뉴 한글 테두리를 짙은 갈색으로 변경했습니다. 선택 항목은 금빛 본문색으로 구분합니다.
- 일반 텍스트·자막의 기존 색상표 29개는 바이트 단위로 동일합니다. 한글 글리프 팩도 v3와 같습니다.
- 메뉴 전용 색상은 공유 프레임버퍼 팔레트를 사용합니다. 같은 글리프를 가진 LOWFONT/LONORMAL의 서로 다른 내장 팔레트 때문에 별칭마다 테두리 색이 달라지지 않도록 했습니다.
- v3의 SAVEGAME을 새 복사본으로 가져왔습니다. Steam 원본은 수정하지 않았습니다.

자동 테스트 61개와 원본 렌더러를 실행하는 격리 검사의 86가지 색상 상태가 통과했습니다. `contrast_probe/menu_contrast_summary.png`는 밝은 배경 위의 에뮬레이터 출력이며 실제 게임 캡처는 아닙니다. 실제 메뉴 화면의 대비는 사용자 확인이 남아 있습니다.

줄바꿈·화면별 글꼴 크기 및 남은 미번역 범위는 이전 시험본과 같습니다.
