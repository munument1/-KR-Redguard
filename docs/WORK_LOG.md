# 작업일지

날짜는 한국 시간(KST) 기준입니다. 주요 결정, 변경 근거, 실제 확인 범위와 남은 문제를 기록합니다. 상세 구현과 설치 절차는 연결된 문서를 참고하세요.

## 2026-10-13 — 기본 한국어 패치 0.1.0 공개

- RTX 4,866건의 번역 전수 검수 완료본을 반영했습니다. 활성 검수 보류는 0건입니다.
- 메뉴·키 이름·도입부 자막과 UTF-8 한글 출력을 묶고, 글꼴별 색상 및 밝은 메뉴 배경의 글자 대비를 보완했습니다.
- 게임 원본과 음원을 포함하지 않는 차분 패키지로 배포하고, 원본 백업과 복원 기능을 제공했습니다.
- 자동 테스트 65개, 색상 검사, 배포 EXE의 설치·재적용·복원을 확인했습니다. 사용자 확인은 메뉴·도입부·인게임 자막 표시까지였으며, 전체 게임 플레이 검증은 완료하지 않았습니다.

## 2026-10-13 — 항구 아이템 화면 충돌 조사와 0.1.1 배포

**증상:** 기본 한패에서 항구 도착 후 편지 아이템 화면 직전에 개발자 콘솔이 나타나고 종료됐습니다. 사용자는 Steam 원본이 같은 장면을 통과함을 확인했습니다.

**조사:** 처음에는 긴 한글 편지의 줄바꿈·출력을 의심했습니다. 해당 코드의 격리 실행은 통과했지만 실제 게임 전체 팝업의 정상 동작을 증명하는 검사는 아니었습니다. 사용자가 기본 한패 실행본으로 충돌을 재현했고, 편지 본문만 영어로 되돌려도 같은 문제가 발생했습니다.

**확인된 실패 지점:** 사용자 스크린샷에 `ERROR!(2) Out of memory`, `3dlib.c:435`가 표시됐습니다. 코드상 아이템 화면용 `3DART/INVENTRY.ROB`의 OARD 데이터 2,281,872바이트를 할당하는 단계였습니다. 모델 파일은 Steam 원본과 일치했습니다.

| 비교 조건 | 확인 결과 |
| --- | --- |
| 기본 한패, `heap_kbytes=22000` | 사용자 충돌 재현 |
| 편지 본문만 영어 원문, `heap_kbytes=22000` | 같은 충돌 재현 |
| 기본 한패 전체 번역 유지, `heap_kbytes=20000` | 사용자 편지 표시·정상 진행 확인 |

**조치:** 3D 매니저가 미리 예약하는 heap을 최대 20000 KiB로 조정해 일반 메모리 할당 여유를 확보했습니다. 번역·글꼴·색상·실행 파일의 네 차분은 0.1.0과 동일합니다. 기존 한패·URP 설치자는 설정만 적용하는 **항구 충돌 수정** 기능을 사용할 수 있도록 했습니다.

**검증과 배포:** 자동 테스트 77개와 배포 EXE의 신규 설치·0.1.0 업데이트·복원을 통과했습니다. 실제 URP 메뉴와 사용자 키 설정을 둔 업데이트, 다른 설정·세이브 보존, 쓰기 실패 시 롤백도 확인했습니다. 0.1.1을 GitHub와 Nexus에 게시하고 Nexus의 0.1.0 파일은 보관 처리했습니다.

**남은 범위:** 모든 지역과 아이템을 플레이로 확인한 것은 아닙니다. 줄어든 3D 매니저 예약량이 다른 복잡한 장면에 미치는 영향은 추가 확인이 필요합니다. 코드 격리 검사·설치 검사와 실제 게임 재현 결과를 구분해 기록합니다.
