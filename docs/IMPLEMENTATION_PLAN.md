# 구현 및 검증 현황 (2026-10-13)

**후속 갱신:** UTF-8 그리기·너비 계산 후크를 넣은 로컬 시험 EXE와 게임 복사본을 생성했다. 패치 진입점의 에뮬레이터 출력 일치와 자동 테스트 49개를 확인했다. 실제 게임 실행은 사용자 확인 대기다. 아래 초기 단계 기록보다 [시험 EXE 안내](TEST_EXE.md)를 현재 구현 기준으로 삼는다.

## 완료

- Git 초기화, `work/redguard-foundation` 브랜치 생성. 원격 저장소는 새로 만든 빈 저장소임을 확인.
- 정식 Steam 게임 설치본에 읽기 접근 확인. 설치본 원본 파일 수정 없음.
- 외부 FNT·RTX·렌더링 문서 및 모드 관리자 실제 소스 조사, 자료 링크 기록.
- `tools/rtx/rtx_tool.py`: UTF-8 JSON 추출, 바이트 인코딩·길이·오프셋 재계산, 구조/오디오 보존 검증, 소스 SHA 검증.
- `tools/fnt/fnt_tool.py`: 청크/글리프 검증, 투명 PNG 아틀라스, JSON 메트릭 추출. 표준 라이브러리만 필요.
- `python -m unittest discover -s tests -v`로 합성 파일 테스트 실행.
- Steam 원본 RTX 전체 구조 검증, 변경 없는 재구성의 바이트 동일성, 실제 음성 3,933건/나머지 자막 무변경 확인.
- Steam 29개 FNT 전수 파싱과 `REDSEL` 아틀라스 생성. 검수 산출물은 `output/`에 보관하며 Git에서 제외.
- `tools/fnt/hangul_glyph.py` + `replace_glyph`: 설치된 Noto Sans KR에서 `가` 글리프 19×19 생성, REDSEL의 바이트 코드 65 글리프만 교체한 FNT 복제본 생성·파싱 성공.
- `tools/encoding/hangul_report.py`: 번역 텍스트를 기준으로 완성형 한글 음절 및 초중종성 종류·CP949 바이트 요구량 산출.
- 합성 바이너리 기반 자동 테스트에 FNT 글리프 교체 전후 타 글리프 불변 및 CP949 인코딩 라운드트립 포함.
- Unofficial Redguard Patch 1.03 로컬 ZIP의 Map/RTX/INI 변경 자료 확인. Coyle의 `ISLAND:1520` 대화 조건 수정 합본을 로컬에서 생성.
- 원본 9개 맵 **컴파일 및 역컴파일 재검증**, Coyle 변경 내용 확인. 78개의 URP 대사 교정 및 6개의 영화 자막 교정을 한국어 번역 원문용 JSON에 반영.
- 실제 RTX 4,866건을 URP 교정 78건에 따라 재구성한 뒤, **정확히 78건만 수정**되고 음성 3,933건 바이트 무변경 확인. 테스트 15개 통과.

## 미해결

- FNT 런타임 256 제한의 **기계어 수준 원인**(단일 분기인지 배열 크기인지 확인 불가).
- ASCII 코드 치환으로 한글 1글자가 게임 화면에 실제 출력되는지.
- RTX의 16비트 문자열 길이를 사용하는 게임 내부의 최대 버퍼 크기와 줄바꿈 충돌.
- Software 렌더러와 Glide 렌더러의 차이 및 실시간 자막/메뉴 동시 패치.
- 전체 한글 음절을 위한 FNT 확장·글리프 매핑과 개별 UI용 문자열 추출 기능.
- 공개된 다른 언어 번역 패치의 실행 파일 변경 여부(배포된 바이너리 검증 전까지 미확정).
- Coyle의 구출 후 대화 및 친구 관계는 게임 플레이 검증 전. 원본 URP 합본은 **저작권자 허가 없는 공개 배포 불가**.
