# 레드가드 한국어 패치 0.1.0 (초기 공개판)

**갱신:** 항구 도착 후 편지 아이템 화면의 메모리 할당 오류가 확인됐습니다. [0.1.1 안내](RELEASE_0_1_1.md)의 패처 또는 수동 설정을 적용하세요.

Steam 정식판의 Software 실행 파일 RG.EXE용입니다. Windows 10/11 64비트 패처이며 Python을 따로 설치할 필요가 없습니다.

## 설치

1. 게임과 DOSBox를 종료합니다.
2. ZIP 전체를 새 폴더에 압축 해제합니다. EXE와 data 폴더를 함께 두세요.
3. RedguardKoreanPatcher.exe를 실행합니다.
4. Steam의 The Elder Scrolls Adventures Redguard 설치 폴더 또는 그 안의 Redguard 폴더를 선택합니다.
5. 파일 확인 후 패치 적용을 누릅니다.
6. 기존 Steam/DOSBox Software 실행 방법으로 게임을 시작합니다.

RG.EXE, ENGLISH.RTX, MENU.INI, KEYS.INI 네 파일만 바꿉니다. 원본은 같은 폴더의 *.redguard-ko.bak로 백업합니다. 세이브와 설정은 수정하지 않습니다. 쓰기 권한이 없는 폴더라면 해당 폴더에 쓰기 권한을 확보한 뒤 실행하세요.

## 복원

게임을 종료하고 같은 패처에서 설치 폴더를 선택한 뒤 원본 복원을 누릅니다. 백업 파일은 복원 후에도 유지됩니다. 다른 모드가 패치 대상 파일을 변경한 경우 자동으로 덮어쓰지 않고 중단합니다.

## 포함 범위

- RTX 대사·일지·아이템 등 4,866건: 전수 텍스트 검수 완료, 활성 검수 보류 0건.
- 메뉴 표시 문구 47개, 키 이름 21개, 도입부 자막 72개.
- UTF-8 한글 렌더링, 글꼴별 색상, 어두운 메뉴 테두리와 선택 색상.
- 정식 게임 원본·음원은 포함하지 않는 차분 데이터. 정식 게임이 필요합니다.

## 검증과 남은 범위

v4의 인게임 자막·도입부·메뉴 표시는 사용자가 확인했습니다. 최종 검수본 반영 후 자동 테스트 65개, 기본/추가 글자 각각 86가지 색상 검사, 배포 EXE의 확인·적용·재적용·복원·재복원 검사를 통과했습니다. 음원 3,933건은 원본과 같습니다. 최종판의 전체 게임 플레이 검증은 수행하지 않았습니다.

Glide 실행 파일은 지원하지 않습니다. Steam 원본의 SHA-256이 맞는 파일만 지원하며 다른 판본·다른 모드·이전 시험 패치 파일에는 적용되지 않습니다. 이전 시험 폴더 대신 Steam 원본 설치 폴더를 선택하세요. UI 하드코딩 문구와 도입부 이외 동영상 자막(1~4), 텍스처 한글화, 일부 긴 문장의 줄바꿈과 화면별 글꼴 크기는 남아 있습니다. 비공식 패치의 스크립트/Coyle 수정은 이 배포에 포함하지 않습니다.

## 글꼴·구성 요소

추가 한글 비트맵은 Noto Sans KR에서 생성했습니다. 원본 폰트의 저작권은 Adobe에 있으며 해당 비트맵에는 SIL Open Font License 1.1이 적용됩니다. Python, Tcl/Tk, bsdiff4, PyInstaller 관련 고지는 licenses 폴더를 참고하세요.
